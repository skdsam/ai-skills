SELECTION
Used GitHub repository popularity and the weekly Trending page to discover
candidates, then selected missing relevant skill folders. Repository stars are
not a per-skill ranking or a quality guarantee. JUCE/audio is a small niche,
so useful specialist skills with few stars are included and identified above.
UI UX Pro Max and existing matching Blender/other folders were already installed.
The Google weekly Trending results included Stitch Skills and the Modern Web
Guidance source repository; the install uses the published Modern Web Guidance
skill distribution rather than its developer/test skills.

PORTABILITY
Skipped Claude-Code-Game-Studios despite its popularity: its commands depend on
Claude-only dynamic prompts, hook files and agent roles. Installing just those
folders would not make the workflows function in Codex and Antigravity.
Bundled the shared Blender references and JUCE helper scripts once in
skills/_shared. Fixed malformed descriptions and duplicate YAML keys, normalized
Stitch discovery names, disambiguated Blender/Godot export, and adapted the
gamedev router to the flat shared layout. See github-skill-imports-2026-11-20.json
for exact upstream commits, hashes and modifications.

DEPENDENCIES
Installing skill instructions does not install every tool they can invoke.
Blender execution needs Blender (and optionally a Blender MCP connection).
JUCE workflows need C++/CMake/JUCE; some platform workflows need macOS or SDKs.
Stitch workflows need an authenticated Stitch MCP connection.
Earshot requires its Python package, ffmpeg and model setup for audio analysis.
Optional Three.js asset generators require their provider credentials.
Impeccable includes a launcher that may download its helper on first use.
No provider accounts, system packages, audio models, hooks or external services
were configured or executed as part of this import.
